# Einkaufslisten App

Eine einfache Nuxt.js App zur Verwaltung der wöchentlichen Einkaufsliste.

## Features

- Hinzufügen, Bearbeiten und Löschen von Artikeln
- Kategorisierung von Einkaufsartikeln
- Checkboxen zum Abhaken erledigter Artikel
- Persistente Speicherung im LocalStorage
- Mobil-optimiertes Design

## Installation

```bash
# Abhängigkeiten installieren
npm install

# Entwicklungsserver starten
npm run dev

# Für Produktion bauen
npm run build
npm run start
```

## Technologien

- Nuxt 3
- TailwindCSS für das Styling
- LocalStorage für persistente Datenspeicherung
